# Threadkeeper brand assets

- `threadkeeper-app-icon.png`: generated app icon, a golden thread forming a playful lowercase t on a charcoal tile. Created with the built-in image-generation tool.
- `threadkeeper-mark.svg`: flat scalable companion mark for the native UI.
- `threadkeeper-mark-body.svg`: the same paths for Rune’s Icon renderer.

Palette: charcoal #1d1e22, amber #f2b85b. Tagline: Keep the conversation moving.

Generation prompt: One polished macOS app icon for Threadkeeper. Minimal plus playful, no mascot. A thick golden thread forms a loose looping lowercase cursive t, rounded free ends and a subtle over-under crossing. Bold silhouette at small sizes, deep charcoal rounded-square tile, subtle dimensional shading, transparent outside, no typography or mockup.

Legacy `powersync-*` assets are unused historical assets; their branding belongs to PowerSync.
